앱 이름: 마이사(MAISA) · 개발사: 주식회사 더블유투마이스

마이사 계정과 계정에 담긴 모든 데이터의 삭제를 요청하는 방법을 안내합니다. 삭제는 되돌릴 수 없습니다.

방법 1 — 앱에서 직접 삭제 (가장 빠름)

  1. 마이사 앱 실행 후 로그인
  2. 하단 프로필 탭 → 우측 상단 설정
  3. 회원 탈퇴 선택
  4. 안내 문구 확인 후 탈퇴하고 모든 데이터 삭제 누르기

이 경로로 요청하면 계정과 데이터가 즉시 삭제되고 자동으로 로그아웃됩니다.

방법 2 — 이메일로 요청

앱을 이미 삭제했거나 로그인할 수 없는 경우 이메일로 요청해 주세요.
